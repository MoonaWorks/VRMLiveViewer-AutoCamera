# 生成AIを用いたVRMLiveViewer 手動カメラ設定のはじめかた

## 生成AIを使ってAutoCamera JSONを作成・調整する手順

本書は、VRM Live Viewerの手動カメラ設定（Auto Camera Settings）用JSONを、ChatGPTやGeminiなどの生成AIを利用して作成するための手順書です。

本プロジェクトは非公式であり、VRM Live Viewer開発者による公式資料ではありません。

## 1. 用意するもの

- VRM Live Viewer
- ChatGPT、Geminiなど、ファイルを参照できる生成AI
- 本リポジトリのAutoCamera JSON仕様書
- `samples` フォルダのサンプルJSON

## 2. 基本の流れ

| 手順 | 内容 |
|---|---|
| 1 | VRM Live Viewerで使用するキャラクター、モーション、楽曲などを準備する。 |
| 2 | カメラワークを作りたい範囲の開始フレーム・終了フレーム、BPM、キャラクター番号などを確認する。 |
| 3 | 生成AIに「AutoCamera JSON仕様書」と「サンプルJSON」を添付する。 |
| 4 | 欲しいカメラワークを自然言語で指示する。 |
| 5 | 生成されたAutoCamera JSONを `.json` ファイルとして保存する。 |
| 6 | 保存したAutoCamera JSONをVRM Live Viewerへドラッグ＆ドロップする。 |
| 7 | 再生してカメラワークを確認する。 |
| 8 | 必要なら、気になるフレームのカメラ設定を手動で調整する。大幅な変更が必要な場合は、生成AIへ修正内容を伝えてJSONを再生成する。 |
| 9 | 手動でカメラを調整する際、どのパラメータを変更すればよいかわからない場合は、JSONを生成したチャットに質問することで、変更するパラメータの候補を確認できる。 |

## 3. 生成AIへ渡すもの

最低限、次の2ファイルを同じ会話で生成AIに渡します。

- `AutoCamera_JSON_Spec_JA.pdf`
- `full_camera_sample_6660f_160bpm.json`

サンプルJSONは特定の楽曲用プリセットではなく、AutoCamera JSONのアウトプット例です。

水平オービット、ロール、ダッチアングル、横倒し構図、ズーム、ドリー、Jitterなどの組み合わせ方を参照するために使用します。

サンプルJSONは全長6660フレーム、160 BPMを想定し、おおむね小節単位でカメラを切り替えています。

## 4. プロンプトの書き方

曲名は必要ありません。BPMとフレーム数を事前に確認してください。

AIが必要とするのは、カメラを配置するための条件と演出の希望です。

プロンプトの最後には、

> VRM Live Viewerで読み込めるAutoCamera JSONを1行のミニファイ形式で出力してください。

と記載してください。この一文は削除しないでください。

### 例

> 全長6660フレーム、160 BPM、0フレームから開始。  
> キャラクター1固定。  
> かなりアクティブなカメラワークにしてください。  
> 水平360度オービット、画面の360度ロール、45度ダッチアングル、  
> 90度横倒し構図、ズームイン／アウト、ドリー、Jitterを入れてください。  
> タイミングはいったんお任せします。  
>
> VRM Live Viewerで読み込めるAutoCamera JSONを1行のミニファイ形式で出力してください。

## 5. 生成されたJSONを使う

生成AIから受け取ったJSONは `.json` ファイルとして保存し、VRM Live Viewerへドラッグ＆ドロップしてください。

## 6. 再生後の微調整

JSONを作り直さなくても、生成AIに「どの設定値を変えればよいか」を尋ねられます。

フレーム番号と症状を伝えると分かりやすくなります。

| 伝え方の例 | 主な調整候補 |
|---|---|
| 1800フレームの45度傾きが強すぎる | Rotation Z / `angle` Z |
| ズームインを少し弱くしたい | Distance / Add Distance / `distanceMax` |
| 回転をもう少しゆっくりにしたい | Changing Rotation → Changing Time / `rotationTime` |
| 揺れが強すぎる | Jitter → Position Amount / Rotation Amount |
| 横移動を半分くらいにしたい | Changing Position → Add X / `positionMax` X |

## 7. 360度回転について

確認した動作では、360度を1つの回転設定として指定すると180度以降で反転する場合があります。

本資料では、360度回転を180度＋180度の2つの連続したカメラデータとして作成します。

## 8. うまくいかないとき

- **JSONが読み込めない**  
  最終JSONが1行のミニファイ形式か確認する。

- **意図と違うカメラになる**  
  フレーム番号と「何が違うか」をAIに伝える。

- **360度回転が途中で戻る**  
  180度＋180度の2パーツになっているか確認する。

- **設定値の意味が分からない**  
  仕様書のUI名とJSONキー対応表を参照する。

## 9. 詳細仕様

各設定値、UIとの対応、複数カメラパーツの組み合わせ規則は `AutoCamera_JSON_Spec_JA.pdf` を参照してください。
